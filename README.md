# Sales Data Analysis Using Python

 Project Overview

This beginner-level Data Analytics project explores sample sales data to understand product performance, revenue distribution, and monthly sales trends.

 Objectives

* Calculate total sales revenue and quantity sold.
* Identify products generating the highest revenue.
* Analyze monthly revenue trends.
* Visualize sales performance using charts.

 Tools & Technologies

* **Python** — Data analysis
* **Pandas** — Data manipulation and aggregation
* **Matplotlib** — Data visualization
* **Google Colab** — Notebook environment

 Key Analysis

* Total transactions and quantity sold
* Revenue by product
* Monthly sales revenue
* Product revenue comparison chart
* Monthly revenue trend chart

 Project Files

* `Sales_Data_Analysis.ipynb` — Contains the Python code, analysis, and visualizations.

 How to Run

1. Open [Google Colab](https://colab.research.google.com/).
2. Download the notebook from this repository.
3. Upload the notebook to Google Colab.
4. Run each code cell from top to bottom.

 Dataset

A small sample sales dataset created for learning and demonstration purposes.

 Skills Demonstrated

* Exploratory Data Analysis (EDA)
* Data aggregation using Pandas
* Revenue analysis
* Data visualization
* Communicating findings from data
