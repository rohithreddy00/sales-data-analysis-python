
Sales Data Analysis Using Python and SQL

 Project Overview
This Data Analytics project analyzes sample sales data using Python, Pandas, Matplotlib, and SQL to understand sales performance, product revenue, customer behavior, and monthly sales trends.

 Objectives
- Calculate total sales revenue and quantity sold.
- Identify top-performing products.
- Analyze monthly sales trends.
- Examine customer purchasing behavior.
- Summarize key sales performance indicators (KPIs).
- Visualize sales insights using charts.

 Tools & Technologies
- **Python** — Data analysis
- **Pandas** — Data cleaning and aggregation
- **Matplotlib** — Data visualization
- **SQL** — Sales analysis and reporting
- **Google Colab** — Notebook environment
- **GitHub** — Project version control

 Key Analysis
- Total sales revenue and quantity sold
- Product-wise revenue analysis
- Monthly sales trends
- Customer analysis
- Sales summary and KPIs
- Product revenue comparison charts
- Monthly revenue trend charts

 Project Files

 Python
- `Sales_Data_Analysis.ipynb` — Python code, data analysis, and visualizations.

 SQL
- `sql/01_sales_kpis.sql` — Sales performance KPIs.
- `sql/02_product_analysis.sql` — Product performance analysis.
- `sql/03_monthly_sales_trends.sql` — Monthly sales trends.
- `sql/04_customer_analysis.sql` — Customer analysis.
- `sql/05_sales_summary.sql` — Sales summary queries.

 How to Run

 Python Analysis
1. Open [Google Colab](https://colab.research.google.com/).
2. Download `Sales_Data_Analysis.ipynb` from this repository.
3. Upload the notebook to Google Colab.
4. Run the cells from top to bottom.

 SQL Analysis
1. Open the SQL files in the `sql/` folder.
2. Review each query.
3. Run the queries in a compatible SQL environment after configuring the dataset and table structure required by the queries.

 Dataset
A small sample sales dataset created for learning and demonstration purposes.
