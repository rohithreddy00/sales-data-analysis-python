
Sales Data Analysis Using SQL

Project Overview
This project analyzes sales data using SQL to identify key business performance indicators, product performance, monthly sales trends, and customer purchasing behavior.

Objectives
- Calculate total sales revenue and order volume.
- Identify top-performing products.
- Analyze monthly revenue and sales growth.
- Understand customer purchasing behavior.
- Create summary KPIs for sales reporting.

Tools and Technologies
- SQL
- MySQL
- GitHub

SQL Analysis Files

| 02_product_analysis.sql | Product performance and rankings |
| 03_monthly_sales_trends.sql | Monthly revenue and growth |
| 04_customer_analysis.sql | Customer spending and order behavior |
| 05_sales_summary.sql | Overall sales dashboard KPIs |

Key Skills Demonstrated
- SQL aggregate functions: SUM, COUNT, AVG
- GROUP BY and ORDER BY
- Product ranking using RANK
- Monthly trend analysis using LAG
- Common Table Expressions (CTEs)
- Business KPI analysis
- GitHub version control

Business Value
This analysis helps businesses monitor revenue, identify high-performing products, understand customer purchasing patterns, and track monthly sales performance.

Dataset Requirements
The queries assume a sales table containing:
- order_id
- order_date
- customer_id
- product_name
- quantity
- unit_price

 A compatible dataset and database are required to execute the queries.
